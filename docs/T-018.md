## 배경 / 요구사항 참조
- **FR-015**: Goal 관리: 대청봉, 장거리 트레킹, 10km 걷기, 특정 중량, 주 3회 운동, 체지방률 등 목표 등록.
- **FR-016**: Goal Readiness: 목표별 READY 점수(0~100)와 항목별 점수, 부족 영역(개선 필요) 표시.
- **NFR-003**: 개인정보: Supabase RLS로 사용자별 접근 제한.

FR-016 예시:

```text
🏔 대청봉  READY 82 / 100
Strength 88 / Endurance 71 / Balance 76 / Hiking 78 / Recovery 73
⚠ 개선 필요: 오르막 지구력, 하산 근지구력
```
