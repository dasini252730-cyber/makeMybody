## 쉬운 설명

**한 줄 요약**  
여러 번의 체중 측정값으로부터 7일 평균, 30일 추세를 계산하는 순수 함수를 만든다.

**왜 필요한가**  
하루의 체중 변동은 수분/음식/배변 등으로 크게 흔들린다. 사용자가 실제 성장·퇴보 추세를 정확히 인식하려면 7일 평균으로 추세를 보여줘야 한다. 또한 30일 기준 상승/하강/유지 방향을 표시하면 장기 성과를 명확히 할 수 있다.

**끝나면 보이는 것**
- src/lib/weight.ts: movingAverage(logs, days), trend(logs, days) → 'up'|'down'|'flat' 두 함수
- src/lib/__tests__/weight.test.ts: 경계 케이스 테스트 5개 이상 (데이터 1/3/7/30일, 결측 등)
- 데이터가 3일뿐이어도 에러 없이 실행, 30분 내 완료

**주의**  
T-016(body_metrics 테이블)에서 정의한 대로 **날짜별 최신 측정 1건**만 사용한다. 예를 들어 2026-10-12에 3번 측정했으면 마지막 측정값만 취한다. 결측일(측정 기록 없는 날)은 0으로 채우지 않고 행을 제거하므로, 계산 중 "데이터가 없다"는 경우를 처리해야 한다.
