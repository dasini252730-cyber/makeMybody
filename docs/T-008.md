## 쉬운 설명

**한 줄 요약**: 앱 화면 위에 헤더, 아래에 탭 메뉴를 고정시키고, 화면 가운데에 운동 정보를 표시하는 구조를 만드는 작업입니다.

**왜 필요한가**: T-002에서 6개 섹션(HOME, WORKOUT, BODY, GROWTH, GOALS, SETTINGS)의 빈 화면이 만들어졌지만, 아직 사용자가 화면 간에 쉽게 이동할 수 없습니다. 특히 휴대폰에서 한 손으로 빠르게 섹션을 전환할 수 있도록, 탭 메뉴를 화면 아래에 고정시키는 것이 중요합니다.

**끝나면 보이는 것**:
- 앱 아래쪽에 HOME, WORKOUT, BODY, GROWTH, GOALS, SETTINGS 6개 탭이 고정되어 보임
- 각 탭을 클릭하면 해당 화면으로 이동
- 휴대폰(375px)과 데스크톱(1280px) 모두에서 정상 작동
- 터치 버튼이 충분히 커서 한 손으로 쉽게 누를 수 있음 (최소 44px)

**주의**:
- T-002에서 라우터와 6개 뷰가 이미 만들어져 있어야 하므로, T-002를 먼저 완료해야 함
- 30분 안에 끝내려면 모바일 반응형(375px → PC 1280px)의 레이아웃만 구현하고, 애니메이션이나 복잡한 스타일은 나중으로 미뤄야 함
- 안전 영역(safe-area inset)도 고려해서, 노치나 하단 바가 있는 폰에서도 탭 메뉴가 제대로 보여야 함
