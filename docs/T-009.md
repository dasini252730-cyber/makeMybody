## 작업 단계
1. `src/components/ui/` 에 BaseButton, BaseCard, BaseTextField, NumberStepper(±, 길게 누르기 가속), Toast 작성
2. CSS 변수 기반 테마 토큰(`src/assets/tokens.css`)
3. `src/composables/useToast.ts`

## 완료 조건
- [ ] NumberStepper 가 한 손 엄지로 조작 가능

- 특이사항 없음. 코드 줄수 예산(.claude/code-budget.json)과 RLS 원칙을 지킨다.

## 쉬운 설명

**한 줄 요약**: 앱 화면을 만들 때 쓸 기본 UI 부품들(버튼, 카드, 입력창, 숫자 조절, 알림)을 만드는 작업입니다.

**왜 필요한가**: T-008에서 기본 레이아웃이 만들어지면, 그 위에 운동 정보를 표시하고 사용자가 입력할 수 있도록 만들어야 합니다. 특히 휴대폰에서 한 손으로 빠르게 세트와 무게를 입력할 수 있는 NumberStepper와 성공/실패를 알려주는 Toast가 중요합니다.

**끝나면 보이는 것**:
- src/components/ui/ 디렉터리에 Button, Card, TextField, NumberStepper, Toast 컴포넌트들이 완성됨
- /dev/ui 페이지에서 각 컴포넌트가 동작하는 모습을 확인 가능
- src/composables/useToast.ts 에서 앱 전체에서 Toast 알림을 사용할 수 있음

**주의**: 디자인 토큰(기본 색상, 다크모드 색상, 최소 터치 영역 44px 등)을 src/style.css에 정의해야 함 (T-001 리뷰에서 토큰 정의를 T-009로 이관함).
