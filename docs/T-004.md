## 목표
계산 유틸 테스트를 위한 Vitest 환경을 만든다.

## 배경 / 요구사항 참조
- **TECH**: 기술: Vue 3 + Vite / Supabase(PostgreSQL, Auth, RLS, Storage, Edge Functions) / Vercel / AI는 추후 연동.

## 작업 단계
1. vitest, @vue/test-utils, jsdom 설치
2. vitest.config.ts 신규 생성(vite 설정 mergeConfig, environment jsdom, include src/**/*.test.ts)
3. `src/lib/__tests__/sample.test.ts` 예제 작성
4. `npm run test` 스크립트 추가 및 통과 확인

## 완료 조건
- [ ] npm run test 통과
- [ ] src/lib 하위 테스트 파일이 자동 수집됨

## 결정 / 주의 사항
- 특이사항 없음. 코드 줄수 예산(.claude/code-budget.json)과 RLS 원칙을 지킨다.

## 쉬운 설명

**한 줄 요약**: 자동으로 코드 오류를 찾아주는 테스트 도구(Vitest)를 설치하고 첫 예제를 작성하는 작업입니다.

**왜 필요한가**: 운동 데이터를 계산하는 함수들(1RM 추정, Fitness Score 등)이 올바르게 작동하는지 자동으로 확인해야 합니다. 나중에 계산 규칙을 바꿀 때도 기존 기능이 깨지지 않았는지 빠르게 점검할 수 있습니다.

**끝나면 보이는 것**:
- `npm run test` 명령어로 테스트 실행 가능
- src/lib/ 폴더 아래 .test.ts 파일들이 자동으로 발견되고 실행됨
- 간단한 예제 테스트(src/lib/__tests__/sample.test.ts)가 통과함

**주의**:
- T-001에서 Vite 기본 설정이 완료되어야 합니다.
- 30분 안에 끝내려면 계산 함수 본체는 작성하지 않고 간단한 예제(더하기 등)만 테스트해야 합니다.
