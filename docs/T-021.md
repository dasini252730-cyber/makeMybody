## 쉬운 설명

**한 줄 요약**  
누구나 접근할 수 없어야 할 개인 운동 기록이 실제로 보호되는지, 그리고 2명의 사용자가 서로의 데이터를 볼 수 없는지 자동으로 검증하는 테스트를 만든다.

**왜 필요한가**  
공개 URL에 앱이 올라가면 로그인하지 않은 누구나 Supabase에 접근할 수 있다. RLS(Row-Level Security) 정책이 제대로 작동하지 않으면 타인이 내 운동 기록을 읽거나 수정할 수 있다. 따라서 로그인 없이는 아무도 데이터를 건드릴 수 없도록, 그리고 다른 사용자가 내 데이터를 절대 볼 수 없도록 하는 것이 필수다(NFR-004, 수용 기준 1).

**끝나면 보이는 것**
- `npm run db:rls` 명령으로 RLS 검증 테스트 실행 가능
- 테스트 통과 시: anon(로그인 없음)은 모든 P0 테이블 읽기/쓰기 실패, 사용자 A와 B는 서로 데이터를 못 봄 (선택적 읽기/수정/삭제는 모두 0건)
- 실패 시: 누락된 권한 정책 또는 버그를 명확히 지적하는 오류 메시지

**주의**  
T-012(exercise_library), T-013(workout_sessions/session_items), T-014(exercise_sets), T-118(Supabase 스키마 노출)이 모두 완료되어야 이 테스트를 실행할 수 있다. 이미 rls_probe.sql과 rls_probe_workout.sql이 작성되어 있으므로, 모든 P0 테이블과 케이스가 포함되어 있는지 확인하고 필요한 부분만 추가/수정한다. 30분 안에 끝내려면 기존 테스트를 재사용하고, 누락된 테이블이나 케이스만 보강한다.
