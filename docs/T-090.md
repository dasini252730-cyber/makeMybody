## 결정 / 주의 사항
- **확정(2026-10-12, 사용자)**: 공급자 Anthropic Claude API(기본 모델은 가벼운 Haiku 계열, 구조화 출력), 경로 Supabase Edge Function(키는 Supabase secrets 에만, APK 에 넣지 않음), **월 예산 상한 1,000원**. Edge Function 이 월 사용량을 mybody 테이블에 기록해 상한 초과 시 호출을 거부하고 앱은 수동 입력 경로로 안내한다.
- 사용자 준비물(T-091 시작 전): Anthropic 콘솔에서 API 키 발급 → `supabase secrets set ANTHROPIC_API_KEY=...` (제가 명령을 안내). 건강 메모 외부 전송은 설정에서 켠 경우만(NFR-004).
- 비용 감각: 1,000원 ≈ 세션 구조화 수백 회(Haiku 기준). 추천 설명문(T-122)도 같은 예산 안에서.
- **판단 필요**: LLM 공급자(OpenAI API / Anthropic / 개인 로컬 LLM)와 호출 경로(Supabase Edge Function 프록시 권장), 월 예산 상한, 개인 데이터 전송 범위를 사용자가 결정해야 함.
