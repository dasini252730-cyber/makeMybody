## 목표
PostgREST 가 mybody 스키마를 노출하도록 대시보드 Settings → API → Exposed schemas 에 mybody 를 추가한다(수동). 대안인 SQL(authenticator 역할의 pgrst.db_schemas 변경)은 공유 프로젝트 설정 변경이라 자동 승인이 거부됐으므로 사용자 지시가 있을 때만 실행. 마이그레이션 적용(db-apply)에는 필요 없고, 앱/RLS 테스트의 API 접근에 필요.
