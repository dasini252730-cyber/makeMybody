## 쉬운 설명

**한 줄 요약**: 앱의 6개 주요 섹션(HOME, WORKOUT, BODY, GROWTH, GOALS, SETTINGS)에 접근할 수 있도록 네비게이션 구조를 만드는 작업입니다.

**왜 필요한가**: T-001에서 기본 Vite 프로젝트가 만들어졌지만, 아직 앱의 어느 화면도 이동할 수 없습니다. 이 작업으로 6개 주요 섹션이 실제로 작동하는 네비게이션이 생기므로, 향후 각 화면의 기능(운동 기록, 성장 분석, 목표 관리)을 추가할 수 있는 기반이 만들어집니다.

**끝나면 보이는 것**:
- 앱에서 HOME, WORKOUT, BODY, GROWTH, GOALS, SETTINGS 각 탭 또는 메뉴 클릭 시 해당 화면으로 이동
- 브라우저 개발자 도구의 Vue Devtools에서 Pinia 스토어가 보이고 상태를 조회 가능
- 각 섹션의 빈 뷰(View.vue) 컴포넌트가 렌더링되고, URL 경로(`/`, `/workout`, `/body` 등)와 일치

**주의**:
- T-001에서 이미 `src/views/`, `src/stores/` 폴더가 생성되었으므로, 여기서는 라우터 설정 파일과 각 뷰 파일을 추가하는 작업만 수행합니다.
- `vue-router`와 `pinia` npm 패키지 설치가 가장 먼저 필요하고, `main.ts`에 등록해야 함.
- 30분 안에 끝내려면 lazy import 설정에 시간을 쓰지 않고 기본 라우트 정의만 수행할 것.
