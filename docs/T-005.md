## 배경 / 요구사항 참조

2. `.env.example` 에 VITE_SUPABASE_URL / VITE_SUPABASE_PUBLISHABLE_KEY 정의, `.env` 는 gitignore (완료)
3. `src/lib/supabase.ts` createClient 에 `db: { schema: 'mybody' }` (완료)
4. 사용자가 .env 에 값을 넣으면 `supabase.auth.getSession()` 으로 연결 확인

## 쉬운 설명

**한 줄 요약**: 앱이 운동 데이터를 안전하게 저장하기 위한 데이터베이스(Supabase)를 연결하고, 개인 정보를 보호하는 설정을 하는 작업입니다.

**왜 필요한가**: 
운동 기록, 체중, 성과 데이터는 개인 정보이므로 반드시 개인 서버(Supabase)에 저장되어야 합니다. 이 작업이 없으면 사용자의 데이터를 저장할 수 없고, 앱도 동작할 수 없습니다. 또한 Supabase의 RLS(Row Level Security) 기능으로 각 사용자는 자신의 데이터만 볼 수 있도록 설정합니다.

**끝나면 보이는 것**:
- 환경 변수(`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)가 설정되어 앱이 데이터베이스와 연결됨
- `src/lib/supabase.ts` 파일에서 제공하는 클라이언트로 `supabase.auth.getSession()` 호출 가능 (사용자 세션 조회 성공)
- npm install로 @supabase/supabase-js 라이브러리가 설치됨

**주의**: 
- T-001(Vue 프로젝트 설정)이 먼저 완료되어야 이 작업을 시작할 수 있습니다.
- 30분 안에 끝내려면 Supabase 대시보드에서 프로젝트 생성이 빠르게 진행되어야 합니다. 개발용으로 즉시 제공되는 체험 프로젝트를 사용하면 됩니다.
- `.env` 파일은 로컬에서만 생성하고, 버전 관리(git)에는 절대 포함되지 않아야 합니다(gitignore로 이미 설정됨).
