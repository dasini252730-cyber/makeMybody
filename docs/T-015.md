## 쉬운 설명

**한 줄 요약**  
"PT A", "홈 트레이닝" 같은 자주 반복되는 운동 조합을 템플릿으로 저장하고, 템플릿 안의 운동 목록을 관리하는 테이블을 만든다.

**왜 필요한가**  
매번 같은 운동들을 일일이 입력하는 것은 번거롭다. 템플릿을 선택하면 기본 운동 목록과 기본 세트/반복/중량이 자동으로 채워져서, 실제 수행량만 수정하면 된다(FR-004). 이렇게 하면 운동 기록이 빠르고 정확해진다.

**끝나면 보이는 것**
- Supabase 대시보드에 workout_templates, workout_template_exercises 두 테이블
- 자신이 만든 템플릿만 조회/수정 가능, 다른 사용자 템플릿 접근 불가
- 각 템플릿에 여러 운동이 순서대로 연결되고 각 운동의 기본 세트/반복/중량 저장됨

**주의**  
선행 작업 T-012(exercise_library)가 완료되어야 하며, workout_template_exercises에서 exercise_id로 exercise_library를 참조한다. 사용자별 독립적인 템플릿을 지원하므로 RLS 정책은 간단하다.
