## 쉬운 설명

**한 줄 요약**: 로그인이 완료된 Vue 웹앱을 Capacitor를 이용해 Android APK(설치 파일)로 만들어 갤럭시 휴대폰에 설치하는 작업입니다.

**왜 필요한가**: T-007에서 웹앱의 로그인 기능이 완료되었지만, 사용자는 갤럭시 한 대에서만 쓰므로 웹서버 없이 기기에 직접 앱을 설치하는 것이 편합니다. Capacitor는 Vue 코드 변경 없이 웹앱을 모바일 앱으로 패킹해주는 도구입니다. 앱 한 번 설치 후 로그인하면 기기에 저장된 세션으로 항상 접근할 수 있습니다.

**끝나면 보이는 것**:
- package.json에 @capacitor/core, @capacitor/cli, @capacitor/android이 추가됨
- capacitor.config.ts 파일이 생성됨 (앱 ID: kr.mybody.os)
- android/ 폴더가 생성됨 (Gradle 프로젝트, Android Studio에서 열 수 있음)
- APK 파일이 생성되어 갤럭시 휴대폰에 설치됨
- 앱을 열면 로그인 화면 → 홈 화면이 정상 표시됨

**주의**:
- 선행 작업: T-007(이메일 로그인/로그아웃)이 먼저 완료되어야 함. 로그인 기능이 정상 작동해야 APK 테스트도 가능함
- Supabase .env 설정이 정상인지 미리 확인할 것
- 30분 안에 끝내려면: iOS 빌드, 추가 플러그인 통합, 심화된 깊은 링크 커스텀, Capacitor 네이티브 기능 추가 등은 하지 말 것
- Android APK 서명 설정(keystore)은 디버그 빌드로 충분하므로 나중에 해도 됨
- Supabase 매직링크 리다이렉트는 비밀번호 로그인이 기본이므로 이번 단계에서는 신경쓰지 않아도 됨
