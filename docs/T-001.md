## 목표
Vite 템플릿으로 프로젝트를 만들고 src 폴더 구조와 backlog 스크립트를 잡는다.

## 배경 / 요구사항 참조
- **TECH**: 기술: Vue 3 + Vite / Supabase(PostgreSQL, Auth, RLS, Storage, Edge Functions) / Vercel / AI는 추후 연동.

## 작업 단계
1. `npm create vite@latest . -- --template vue-ts` 로 현재 폴더에 생성 (기존 파일 유지 선택)
2. `src/{views,components,composables,stores,lib,types}` 폴더 생성 및 각 폴더 README 한 줄
3. package.json scripts에 `"backlog": "node tools/backlog.mjs"` 추가
4. `npm run dev` 로 기본 화면 확인, 불필요한 샘플 컴포넌트 제거
5. `npm run build` 가 성공하는지 확인

## 쉬운 설명

**한 줄 요약**: 모던 JavaScript 개발 환경(Vue 3 + Vite)으로 프로젝트 틀을 만들고, 코드 구조를 잡는 초기 셋업 작업입니다.

**왜 필요한가**: 앱의 모든 기능(운동 기록, 성장 분석, 목표 관리)이 동작할 기본 기술 기반이 필요합니다. 이 작업이 없으면 코드를 쓸 수 없습니다.

**끝나면 보이는 것**:
- `npm run dev` 실행 시 브라우저에 기본 화면(빈 Vue 앱) 표시
- `npm run build` 성공하여 배포 가능한 파일 생성
- `npm run backlog stats` 실행하면 백로그 통계 조회 가능

**주의**:
- 선행 작업이 없으므로 지금 바로 시작 가능합니다.
- Vite 템플릿은 최신 버전을 사용하되, 샘플 코드는 모두 제거해야 합니다 (HelloWorld.vue 등).
- 30분 안에 끝내려면 Node 24가 설치되어 있어야 하고, npm create 중 "existing files" 질문에서 "overwrite" 선택이 빨라야 합니다.
