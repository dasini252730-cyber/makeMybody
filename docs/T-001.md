## 목표
Vite 템플릿으로 프로젝트를 만들고 src 폴더 구조와 backlog 스크립트를 잡는다.

## 배경 / 요구사항 참조
- **TECH**: 기술: Vue 3 + Vite / Supabase(PostgreSQL, Auth, RLS, Storage, Edge Functions) / Vercel / AI는 추후 연동.

## 작업 단계
1. `npm create vite@latest . -- --template vue-ts` 로 현재 폴더에 생성 (기존 파일 유지 선택)
2. `src/{views,components,composables,stores,lib,types}` 폴더 생성 및 각 폴더 README 한 줄
3. package.json scripts에 `"backlog": "node tools/backlog.mjs"` 추가
4. `npm run dev` 로 기본 화면 확인, 불필요한 샘플 컴포넌트 제거
5. `npm run build` 가 성공하는지 확인
