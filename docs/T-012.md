## 목표
운동 종류 마스터 테이블(공용 + 사용자 정의)을 만든다.

## 배경 / 요구사항 참조
- FR-003 운동 사전: weight_basis 명시(덤벨 편측 vs 합산, 머신 핀 등), 변형은 별도 운동으로 등록하고 parent_exercise_id 로 계열별 조회, 자동 병합 금지.
- NFR-004 RLS: 기본 운동(user_id NULL)은 로그인 사용자 누구나 읽기, 사용자 정의 운동(user_id = auth.uid())은 본인만.
- 요구사항.md 6.2 exercise_library 컬럼 정의, 7.2 변형 분리와 PR 계산 참고.
- 원본: 요구사항.md v1.2 (2026-10-11 개정). 아래 단계·조건은 v1.2 기준.

## 작업 단계
1. exercise_library(id, user_id nullable, name, aliases text[], category, measurement_type, weight_basis, parent_exercise_id self FK, description, is_archived, created_at)
2. CHECK: measurement_type IN (weight,bodyweight,time,distance,complex); weight 타입이면 weight_basis NOT NULL; weight_basis IN (barbell_total,dumbbell_each,added,machine_pin,assisted_minus)
3. RLS: select 는 user_id IS NULL OR user_id = auth.uid(); insert/update/delete 는 user_id = auth.uid()
4. 인덱스: user_id, parent_exercise_id, name trigram 또는 lower(name)

## 결정 / 주의 사항
- 기본 운동(user_id NULL)은 postgres(db-apply/SQL) 또는 service_role 로만 넣는다(T-023 시드). authenticated 는 user_id NULL 로 insert 불가(정책).
- user_id 기본값 auth.uid() (보정 20261012114000). 클라이언트는 user_id 를 보내지 않는다.
- parent_exercise_id 는 기본 운동 또는 본인 운동만 허용(트리거). 2단계 순환(A→B→A)은 막지 않음 — 재귀 계열 조회를 쓰게 되면 후속 작업.
- 아카이브된 운동과 같은 이름 재등록은 unique 로 거부됨 → 폼에서 "보관된 운동 복원" 안내(T-026).
- 타인 행 update/delete 는 오류가 아니라 0건 → repo 계층은 반환 건수를 확인해 실패를 숨기지 않는다(NFR-003, T-024/T-026 조건).
- 공용 set_updated_at 함수는 이 파일에 처음 정의하고 이후 파일에서 create or replace 로 재정의해 순서 의존을 없앴다.

## 쉬운 설명

**한 줄 요약**  
"스쿼트", "데드리프트" 같은 운동들을 이름, 카테고리, 입력 방식과 함께 저장하는 운동 종류 목록 테이블을 만든다.

**왜 필요한가**  
사용자가 운동을 기록할 때 운동 이름을 검색해서 선택할 수 있게 해준다. 또한 weight_basis(덤벨 편측 vs. 합산, 머신 핀 등)를 명시하면 몇 달 뒤 같은 운동의 기록을 올바르게 비교할 수 있다. 변형 운동(백스쿼트 vs. 고블릿 스쿼트)을 별도 운동으로 등록하되 parent_exercise_id로 계열끼리 묶어 볼 수 있다.

**끝나면 보이는 것**
- 기본 운동들(스쿼트, 데드리프트 등 프리셋)을 모든 로그인 사용자가 읽을 수 있음
- 사용자가 추가한 커스텀 운동(예: "PT 맞춤 운동")은 자신만 볼 수 있음
- Supabase 대시보드에서 exercise_library 테이블 확인 가능

**주의**  
T-012 는 마이그레이션 생성과 기본 운동 seed 데이터만 포함한다. Fitness Score 계산(요구사항 7.5에서 "MVP 제외")에 필요한 area_weights 컬럼은 추후 작업에서 추가할 수 있다. 또한 seed.sql 은 처음에 비어있어도 되고, 운동 추가는 P1 단계에서 할 수 있다.
