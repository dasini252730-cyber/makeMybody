## 목표
결정된 방식으로 세션 저장 시 PR 을 갱신한다.

## 배경 / 요구사항 참조
- **FR-005**: 운동 PR: 운동별 Best Weight / Best Reps / Estimated 1RM 자동 계산. PR 갱신 시 성장 이벤트 표시.

FR-005 예시:

```text
🔥 NEW PR

Squat
40kg × 10

지난 기록 대비 +5kg
```

## 작업 단계
1. exercise_prs(user_id, exercise_id, best_weight, best_reps, est_1rm, achieved_at, prev_*) 테이블 + RLS
2. 저장 직후 computePRs 로 비교/upsert (또는 트리거)
3. 갱신된 PR 목록을 save() 반환값에 포함

## 완료 조건
- [ ] 세션 저장 후 PR 테이블 갱신
- [ ] 갱신 여부가 반환됨

## 결정 / 주의 사항
- 특이사항 없음. 코드 줄수 예산(.claude/code-budget.json)과 RLS 원칙을 지킨다.
