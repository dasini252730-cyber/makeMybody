## 목표
영역별 입력 지표, 최근 가중치, 스무딩 규칙을 문서로 확정한다.

## 배경 / 요구사항 참조
- **FR-007**: Fitness Score 계산: Strength/Power/Endurance/Coordination/Lower Body/Upper Body/Hiking 영역 0~100. 최근 데이터 가중, 급격한 변동 억제.

## 작업 단계
1. 영역별 입력 지표 초안: Strength=상위 1RM, Power=점프/올림픽 볼륨, Endurance=걷기·등산 시간/거리, Coordination=복합동작 빈도, Lower/Upper=부위별 볼륨, Hiking=거리·고도·빈도
2. 최근성 가중: 지수 감쇠(반감기 28일)
3. 스무딩: 전일 점수와 EMA
4. 스케일: 개인 기준선(첫 4주 평균=50) 제안
5. 사용자 승인 후 `docs/fitness-score.md` 확정

- **판단 필요**: 7개 영역의 입력 지표와 가중치, 최근성 반감기(예: 28일), 스무딩(EMA α=0.3 제안), 점수 스케일 기준(개인 최고 대비 vs 절대 기준)을 사용자가 확정해야 함. 제안 초안을 docs 에 작성했으니 승인/수정 필요.
