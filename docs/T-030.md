## 목표
한 손으로 세트를 빠르게 입력하는 UI 를 만든다.

## 배경 / 요구사항 참조
- **FR-002**: 운동 기록: 날짜, 운동 종류, 운동명, 세트, 반복, 중량, 시간, 거리, 난이도, 메모.
- **NFR-004**: 모바일 우선: 한 손으로 빠르게 기록.

FR-002 예시:

```text
2026-10-07

Deadlift
40kg × 10
40kg × 10
50kg × 5

OHP
20kg × 20

Workout Duration
55분
```

## 작업 단계
1. `components/workout/SetRow.vue`: 중량 스텝퍼(±2.5kg), 반복 스텝퍼(±1)
2. '+ 세트' 는 직전 세트 값을 복사
3. 세트 스와이프 삭제
4. input_type 에 따라 reps 만/weight+reps 전환

## 완료 조건
- [ ] Deadlift 40×10, 40×10, 50×5 를 10탭 이내 입력
- [ ] 숫자 키패드가 뜨지 않아도 입력 가능
