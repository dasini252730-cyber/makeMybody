## 목표
문장을 운동 데이터 JSON 으로 바꾸는 프롬프트와 출력 스키마를 만든다.

## 배경 / 요구사항 참조
- **FR-020**: 자연어 운동 입력: 문장을 구조화된 운동 데이터로 변환 (V1.1).
- **AI-001**: 자연어 운동 기록 구조화.

FR-020 예시:

```text
오늘 PT에서 점프 10회 하고 한발 점프 스텝 30회, 사이드 점프 20회, 20kg 중량 운동하고 OHP 20회 했어.
→ Jump 10 / Single Leg Step 30 / Side Jump 20 / Weighted 20kg / OHP 20 reps
```

## 작업 단계
1. 출력 JSON 스키마(exercises[].{name, sets[], reps, weight_kg, duration}) 정의
2. 라이브러리 이름 매칭 규칙(한/영)
3. 요구사항 예시 문장으로 테스트
